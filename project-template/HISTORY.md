# {{PROJECT_NAME}} history

A short record of what is being done in {{PROJECT_NAME}}, newest first, for
anyone visiting the repository. Each line is one change; the reasons and the
details are in the [project log](docs/project-log.md), the
[decisions](docs/decisions.md) and the pull requests, and the current state
is on the [progress dashboard](docs/dashboard/README.md).

How to write a line: one change, one sentence or two, in plain words for a
visitor, prefixed `Added:`, `Changed:`, `Fixed:` or `Removed:`, with the
pull request numbers at the end. When a release is made, the "since"
heading becomes "Changes in VERSION (DATE)" and a new "since" heading goes
on top.
