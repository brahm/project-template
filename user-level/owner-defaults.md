# Defaults for new projects

When I start a project, use these without asking, unless the brief says
otherwise. Ask me only for what is still written as "ask me".

- Owner: OWNER_NAME
- Language of reports and of the dashboard: OWNER_LANGUAGE (dashboard code DASHBOARD_LANG)
- Language of the repository (code, comments, documentation, commits): REPO_LANGUAGE
- Time zone: TIMEZONE
- Licence: LICENSE
- GitHub account for new repositories: GITHUB_ACCOUNT
- Technology I prefer when the brief does not choose one: ask me
